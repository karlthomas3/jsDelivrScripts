# jsDelivrScripts

just a repo for non-sensitive scripts to be used with jsDeliver

## to use scripts

```
<script src="https://cdn.jsdelivr.net/gh/karlthomas3/jsDelivrScripts@latest/<SELECTED PROJECT>/awaitRedTrackRedirect.js"
  type="text/javascript">
</script>
```

and replace `<SELECTED PROJECT>` with correct directory or just use the template
index.html
